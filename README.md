# API для Умного Дома

Это репозиторий представляет собой API для управления и мониторинга состояния вашего жилища, разработанный на языке C# с использованием ASP.NET Core. Этот API предоставляет ряд функций для управления устройствами умного дома, их состоянием и получения актуальной информации о вашем окружении.

## Функционал

API включает следующие функции:

### Управление комнатами
- **Добавление новой комнаты**: Метод `AddAsync` позволяет добавить новую комнату.
- **Обновление существующей комнаты**: Метод `EditAsync` позволяет обновить информацию о комнате по идентификатору.

### Управление устройствами
- **Просмотр списка устройств**: Метод `GetAsync` позволяет получить список всех подключенных устройств.
- **Добавление нового устройства**: Метод `AddAsync` позволяет добавить новое устройство в конкретную комнату.
- **Обновление устройства**: Метод `EditAsync` позволяет обновить информацию о существующем устройстве.
- **Удаление устройства**: Метод `DeleteAsync` позволяет удалить устройство из системы.

## Начало работы

Чтобы запустить API локально, выполните следующие шаги:

1. Клонируйте репозиторий: https://github.com/EkaVolkova/HomeApi.
2. Убедитесь, что у вас установлен .NET SDK (версия 5.0 и выше).
3. Запустите приложение.
4. Откройте Postman или любой другой клиент API и перейдите по адресу `http://localhost:5000/api` для доступа к API.

## Использование функций API

### 1. Управление комнатами

#### 1.1 Добавление новой комнаты

**Postman**
1. В Postman выберите метод **POST**.
2. Введите URL: `http://localhost:5000/rooms/Add`.
3. В закладке **Body** выберите **raw** и выберите **JSON** в выпадающем списке.
4. Вставьте следующий JSON:
```json
{
  "name": "Новая комната"
}
```   
5. Нажмите **Send**.

**Swagger**
1. Перейдите по адресу `http://localhost:5000/swagger`.
2. Найдите метод `POST /rooms/Add`.
3. Нажмите **Try it out**, введите имя комнаты и нажмите **Execute**.

#### 1.2 Обновление существующей комнаты

**Postman**
1. В Postman выберите метод **PUT**.
2. Введите URL: `http://localhost:5000/rooms/Edit{id}`, заменив `{id}` на идентификатор нужной комнаты.
3. В закладке **Body** выберите **raw** и выберите **JSON** в выпадающем списке.
4. Вставьте следующий JSON:
```json
{
  "newName": "Обновленное имя комнаты"
}
```
5. Нажмите **Send**.

**Swagger**
1. Перейдите по адресу `http://localhost:5000/swagger`.
2. Найдите метод `PUT /rooms/Edit{id}`.
3. Нажмите **Try it out**, замените `{id}` на идентификатор комнаты, введите новое имя комнаты и нажмите **Execute**.

### 2. Управление устройствами

#### 2.1 Получение списка устройств

**Postman**
1. В Postman выберите метод **GET**.
2. Введите URL: `http://localhost:5000/devices`.
3. Нажмите **Send**.

**Swagger**
1. Перейдите по адресу `http://localhost:5000/swagger`.
2. Найдите метод `GET /devices`.
3. Нажмите **Try it out** и затем **Execute**.

#### 2.2 Добавление нового устройства

**Postman**
1. В Postman выберите метод **POST**.
2. Введите URL: `http://localhost:5000/devices/Add`.
3. В закладке **Body** выберите **raw** и выберите **JSON** в выпадающем списке.
4. Вставьте следующий JSON:
```json
{
  "name": "Новое устройство",
  "location": "Кухня"
}
```
5. Нажмите **Send**.

**Swagger**
1. Перейдите по адресу `http://localhost:5000/swagger`.
2. Найдите метод `POST /devices/Add`.
3. Нажмите **Try it out**, введите данные устройства и нажмите **Execute**.

#### 2.3 Обновление устройства

**Postman**
1. В Postman выберите метод **PATCH**.
2. Введите URL: `http://localhost:5000/devices/Edit{id}`, заменив `{id}` на идентификатор нужного устройства.
3. В закладке **Body** выберите **raw** и выберите **JSON** в выпадающем списке.
4. Вставьте следующий JSON:
```json
{
  "newLocation": "Гостиная"
}
```
5. Нажмите **Send**.

**Swagger**
1. Перейдите по адресу `http://localhost:5000/swagger`.
2. Найдите метод `PATCH /devices/Edit{id}`.
3. Нажмите **Try it out**, замените `{id}` на идентификатор устройства, введите новое местоположение и нажмите **Execute**.

#### 2.4 Удаление устройства

**Postman**
1. В Postman выберите метод **DELETE**.
2. Введите URL: `http://localhost:5000/devices/Delete{id}`, заменив `{id}` на идентификатор удаляемого устройства.
3. Нажмите **Send**.

**Swagger**
1. Перейдите по адресу `http://localhost:5000/swagger`.
2. Найдите метод `DELETE /devices/Delete{id}`.
3. Нажмите **Try it out**, замените `{id}` на идентификатор устройства и нажмите **Execute**.

### Другие клиенты API

Вы можете использовать любой другой HTTP-клиент для выполнения запросов к API. Убедитесь, что используете правильный метод (GET, POST, PATCH, DELETE) и соответствующий URL с данными в формате JSON в теле запроса, как указано выше.
